NumPy vs. Python puro

Operar sobre todo el arreglo de una vez («vectorizar»), no número por número

El experimento de ayer, recordado

Calcular estadísticas con bucles

  • Ayer calculamos promedio/máximo/mínimo/conteo con bucles y acumuladores manuales.
  • Funciona, pero: cada iteración de un bucle Python reevalúa el tipo de cada elemento (tipado dinámico).
  • NumPy almacena datos de un solo tipo en un bloque contiguo de memoria y opera en código C compilado.
⏱️

¿Cuánto más rápido creen que es NumPy?

Sobre un arreglo de 2 millones de valores, calculando promedio/máx/mín/conteo.

Órdenes de magnitud, no porcentajes. Lo vemos medido en la práctica.
El mismo cálculo, dos formas

Bucle vs. NumPy

# Bucle Python puro
suma = 0.0
for v in datos:
    suma += v
promedio = suma / len(datos)

# NumPy vectorizado
arr = np.array(datos)
promedio = arr.mean()
NumPy: lo esencial

Arreglos, formas y reducción

  • dtype — el tipo de dato de TODOS los elementos del arreglo (ej. float32); a diferencia de una lista Python, no puede mezclar tipos.
  • shape — el tamaño de cada dimensión, como una tupla. Ej.: (24, 30, 40) es un arreglo de 3 dimensiones (ndim=3) con 24, 30 y 40 elementos en cada eje respectivamente.
  • Indexado y slicing multidimensional: arr[:, 0] ("todos los elementos del primer eje, solo el índice 0 del segundo"), arr[1:3, :].
  • Reducciones: mean, std, max, min — con el parámetro axis, que indica sobre cuál dimensión se reduce (clave para todo lo que viene después).
Broadcasting

Operar arreglos de formas distintas sin bucles

  • NumPy "estira" el arreglo más chico para que calce con el más grande, sin escribir bucles.
  • Ejemplo: una grilla (niveles, lat, lon) y una corrección distinta para cada nivel (5 valores).
  • Para que NumPy sepa que esos 5 valores van por nivel, se les da la forma (5, 1, 1): correccion[:, np.newaxis, np.newaxis]. NumPy repite cada valor en toda su capa.
  • Si las formas no calzan, NumPy da error: imprimir .shape de cada arreglo suele mostrar el problema.
Broadcasting

Perfil vertical + grilla horizontal

grilla(niveles, lat, lon) + perfil(niveles, 1, 1) → resultado(niveles, lat, lon)

El perfil se "expande" virtualmente sobre lat/lon sin copiar datos en memoria.

Xarray: arreglos con nombre

La estructura que vamos a usar en el resto del curso

El problema

Un arreglo NumPy "olvida" qué es cada eje

  • (24, 30, 40) — ¿tiempo, lat, lon? ¿nivel, lat, lon? Hay que recordarlo mentalmente o llevar la cuenta en comentarios.
  • Frágil, y fuente común de errores silenciosos al analizar datos de modelos.
Las dos piezas de Xarray

DataArray y Dataset

DataArray

  • Arreglo NumPy + nombres de dimensión + coordenadas + atributos
  • Ej.: temperatura indexada por tiempo y estacion

Dataset

  • Colección de DataArray que comparten dimensiones
  • Análogo a una tabla con varias columnas, pero en N dimensiones
Construcción

Un DataArray desde cero

Pandas para series temporales

El formato natural de un registro horario de estación

Series y DataFrame

Datos tabulares indexados en el tiempo

  • DatetimeIndex: usar fechas reales como índice (en vez de un número de fila) habilita seleccionar serie["2026-01"] ("todo enero") o filtrar por hora, de forma declarativa — sin escribir un if comparando fechas manualmente.
  • resample("1D").mean(): agregación temporal. Ejemplo concreto: 168 datos horarios (una semana) se convierten en 7 promedios diarios con una sola línea.
  • Es una generalización de groupby sobre intervalos de tiempo — agrupa por "cada día" o "cada mes" en vez de por una columna categórica.
Ejemplo

De horario a promedio diario

serie_horaria = ds["temperatura"].sel(estacion="Campo de Marte").to_series()

diaria = serie_horaria.resample("1D").mean()
maximos_mensuales = serie_horaria.resample("1ME").max()

Matplotlib: Figure y Axes

El modelo mental detrás de cada gráfico del curso

Dos objetos, no uno

Figure (el lienzo) vs. Axes (los ejes)

Figure

  • El "lienzo" completo
  • Puede contener varios Axes (paneles)

Axes

  • El sistema de ejes donde se dibuja
  • Título, etiquetas, leyenda, límites

Repaso antes de la práctica

Cómo encajan las 4 librerías de hoy

  • NumPy — el cálculo vectorizado de base (arreglos, broadcasting, reducciones).
  • Xarray — le pone nombre a los ejes de ese cálculo (dimensiones, coordenadas, .sel/.isel).
  • Pandas — el eje temporal (DatetimeIndex, resample).
  • Matplotlib — comunica el resultado (Figure/Axes, uno o varios paneles).
  • El Módulo 2 retoma el Dataset de Xarray de hoy, pero leído desde un NetCDF/GRIB real, no construido a mano.
