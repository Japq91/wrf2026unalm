¿Qué valor del modelo comparamos con la estación?

  • La estación casi nunca coincide con un nodo de grilla exacto.

Métricas de error

Qué mide cada una, y por qué se reportan varias

El ejemplo de las próximas diapositivas

3 horas, 3 pares de valores

  • Hora 1: observado 20°C, simulado 22°C (error = +2)
  • Hora 2: observado 18°C, simulado 17°C (error = −1)
  • Hora 3: observado 25°C, simulado 28°C (error = +3)
  • Con estos 3 pares calculamos bias, MAE y RMSE, para ver qué mide cada fórmula.
Notación

Qué significa cada letra en las fórmulas siguientes

  • n: número de pares observado/simulado (en el ejemplo, n = 3).
  • i: el número de cada par, de 1 a n.
  • si: el valor simulado (por el WRF o el modelo que se valida) en el momento i.
  • oi: el valor observado en ese mismo momento.
  • Σ: suma del término que sigue para i de 1 a n. Con n = 3, Σ(si − oi) es (s₁−o₁) + (s₂−o₂) + (s₃−o₃).
  • s̄, ō: el promedio de los valores simulados y de los observados.
Sesgo

bias

bias = promedio de (simulado − observado)  →  np.mean(sim - obs)

El promedio de las diferencias simulado menos observado. Dice si el modelo sobreestima o subestima, pero no cuánto se dispersan los errores.

  • En el ejemplo: bias = (2 + (−1) + 3) / 3 = 4/3 ≈ +1,33 °C. En promedio, el modelo sobreestima un poco más de un grado.
Tamaño del error

MAE: error absoluto medio

MAE = promedio de |simulado − observado|  →  np.mean(np.abs(sim - obs))

Como el bias, pero con el valor absoluto de cada diferencia antes de promediar. Así un error de +2 y uno de −2 no se cancelan: los dos cuentan 2.

  • En el ejemplo: MAE = (|2| + |−1| + |3|) / 3 = 6/3 = 2,0 °C. Es mayor que el bias (1,33) porque el −1 ya no resta.
Pesa más los errores grandes

RMSE: raíz del error cuadrático medio

RMSE = raíz del promedio de (simulado − observado)²  →  np.sqrt(np.mean((sim - obs)**2))

Cada diferencia se eleva al cuadrado, se promedian los cuadrados y se saca la raíz. La raíz devuelve el resultado a las unidades de la variable (°C en vez de °C²).

  • En el ejemplo: RMSE = √[(2² + (−1)² + 3²)/3] = √(14/3) ≈ 2,16 °C. Es mayor que el MAE (2,0) porque el error de 3 pesa 9 al elevarlo al cuadrado.
  • Un error de 4 pesa 16 antes de la raíz, cuatro veces lo que pesa uno de 2. En el MAE pesaría el doble.
  • Siempre RMSE ≥ MAE. Si el RMSE es bastante mayor que el MAE, hay pocos errores grandes más que muchos moderados.
🧮

¿Puede RMSE ser menor que MAE alguna vez?

Vuelvan al ejemplo: ¿qué pasa con un error de 3 al elevarlo al cuadrado?

No. Se puede demostrar: la raíz del promedio de los cuadrados nunca es menor que el promedio de los valores absolutos. En el ejemplo, 2,16 > 2,0.
El patrón

r: correlación

¿Sube cuando la observación sube y baja cuando baja?  →  np.corrcoef(sim, obs)[0, 1]
  • Va de −1 a 1. 1: las dos curvas suben y bajan juntas; 0: no tienen relación; −1: una sube cuando la otra baja.
  • Solo mira la forma de la curva: no le importa si el modelo está más caliente o más frío.
  • Si el modelo marca 3 °C más en cada hora (23, 21, 28), las curvas tienen la misma forma y r = 1, aunque el modelo se equivoque en 3 grados.
  • Por eso r se reporta junto con una métrica de sesgo o de error.
😬

¿Un modelo con r = 0.95 puede estar sistemáticamente mal?

¿r alto garantiza que el modelo es bueno?

Sí: r mide el patrón, no el sesgo. Por eso se reportan varias métricas.
Tres cosas en un número

KGE: eficiencia de Kling-Gupta

KGE = 1 cuando el modelo acierta las tres cosas a la vez; cuanto más baja, peor
  • ¿Sigue el patrón? → r (ideal 1).
  • ¿Acierta el promedio? → β = promedio del modelo ÷ promedio observado (ideal 1; 1.1 = sobreestima 10 %).
  • ¿Acierta cuánto sube y baja? → α = variabilidad del modelo ÷ variabilidad observada (ideal 1; 0,5 = el modelo varía la mitad).
  • El KGE mide qué tan lejos están esas tres cosas de lo ideal. Si sale bajo, se mira r, β y α por separado para saber cuál falla.
  • Puede salir negativo. Eso indica un ajuste malo, no un error de cálculo.
Como mínimo, reporten una métrica de error (RMSE o MAE) y una de patrón (r o KGE).
Una sola métrica puede esconder el problema.
